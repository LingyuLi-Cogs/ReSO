MoReBench dataset, vendored for offline evaluation.

- morebench_public.csv: 500 neutral moral dilemmas (daily_dilemmas /
  ai_risk_dilemmas / expert_written_*), each with a weighted rubric of
  ~23 criteria (identifying / logical / clear / helpful / harmless
  dimensions, positive and negative weights).
- morebench_theory.csv: 150 dilemmas, 30 per normative framework
  (Kantian Deontology, Act Utilitarianism, Aristotelian Virtue Ethics,
  Scanlonian Contractualism, Gauthierian Contractarianism).

Source: https://huggingface.co/datasets/morebench/morebench (CC BY 4.0)
Code:   https://github.com/morebench/morebench
