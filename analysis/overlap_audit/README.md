# 旧版划分：文本重叠的影响界限

本计算区分“固定检查点剔除重复验证样本后的指标变化”与“改变训练划分并重训的因果影响”。前者的一些指标可给出数学界限，后者不能仅凭重叠比例确定。

## 计算口径与适用范围

- 使用原 `dataset/` 中的 train/val/test，而非新建的 `dataset/action_grouped/`。
- 验证样本按当前 `training/reso_train.py` 的原函数重建：seed=42、RSA 每个维度 150 条、判断监测每个维度 100 条，去重后判断样本共 478 条。
- 文件夹没有实际训练运行的 args.json 或逐条模型输出。因此，固定验证样本的数值以“投稿实验使用这些默认设置”为条件；完整 CSV 的重叠计数不依赖该假设。
- “重叠”指原始 action 文本在训练数据池中存在，不代表已经证实该条目在某次具体训练中被采样，更不代表模型记住了它。
- 数据和模型均未修改。合成压力测试明确使用验证标签构造相似度，不是模型实测或影响概率估计。

## 实际涉及范围

| 范围 | 总量 | 与训练文本重叠或涉及重叠的数量 | 比例 |
| --- | ---: | ---: | ---: |
| 完整旧验证集展开行 | 25,170 | 4,714 | 18.7286% |
| 完整旧测试集展开行 | 25,141 | 4,803 | 19.1043% |
| 默认三分类判断验证样本 | 478 | 83 | 17.3640% |
| 默认 RSA 验证样本 | 750 | 136 | 18.1333% |
| RSA 有效域内样本对：至少一端重叠 | 55,813 | 18,439 | 33.0371% |
| RSA 有效域内样本对：两端均重叠 | 55,813 | 1,825 | 3.2698% |
| 默认验证三元组：至少一个样本重叠 | 16,640 | 7,011 | 42.1334% |

RSA 完全由未与训练文本重叠的样本构成的有效样本对为 37,374 个。这里的样本对相互依赖，不应把 55,813 对当作独立观测来估计置信区间。

## 判断准确率：固定模型时的严格界限

令 A 为当前 478 条上的总体准确率，A_clean 为剔除 83 条重叠样本后、同一个模型在剩余 395 条上的准确率，A_overlap 为重叠组准确率。则：

```text
478 A = 395 A_clean + 83 A_overlap
0 <= A_overlap <= 1

max(0, (478 A - 83) / 395) <= A_clean <= min(1, 478 A / 395)
```

不指定 A 时，|A - A_clean| <= 83/478 = 17.3640 个百分点。若已知 A，界限更紧：

| 假设总体准确率 A（示例，非模型实测） | 剔除后的准确率至少 | 最多下降 |
| --- | ---: | ---: |
| 69% | 62.4861% | 6.5139 个百分点 |
| 70% | 63.6962% | 6.3038 个百分点 |
| 75% | 69.7468% | 5.2532 个百分点 |
| 78% | 73.3772% | 4.6228 个百分点 |

最低值对应“所有重叠样本都答对”。实际剔除后也可能升高，取决于重叠组是否比其余样本更容易。上述示例按连续准确率计算，若有实际正确条数，可以进一步使用整数计数和舍入范围。

这不是“去掉训练重复数据并重训后，准确率最多损失这么多”的保证。重训和重新选模可能改变所有样本的预测。

## RSA：涉及比例不是分数偏移上限

RSA 使用 Spearman 秩相关；删除部分样本对会重新改变剩余数据的秩和归一化，不能用 33.0371% 直接扣减相关系数，也不能把整体相关写成两个子集相关的简单加权平均。定义参见 [SciPy spearmanr 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.spearmanr.html)。

为了检查“这些比例是否足以给未见文本增益提供一个正的保底值”，脚本构造了一个刻意悲观的合成反例：

- 对 705 个不同 action 文本各分配一个合成单位向量，同一文本在不同记录中共享向量。
- 未重叠文本之间的全部余弦相似度在前后两个状态中逐项完全一致。
- 只改动至少一端属于重叠文本的关系；这些关系的目标刻意利用了验证集人类标签。对相同文本对的多条人类标签先聚合，避免给同一输入对分配不同模型余弦。
- 通过 36 轮二分调节，特意将两个全体 RSA 值校准到附带 ReSO 曲线的初始值和峰值。这个校准不是重新测量原模型。
- 两个合成相似度矩阵都是对角为 1、严格对角占优的正定矩阵，因此确实可以作为单位向量的 Gram 矩阵，而不只是任意填出的非物理相似度表。

| 合成状态 | 全体 RSA | 仅未重叠文本之间的 RSA |
| --- | ---: | ---: |
| 校准到初始值 | 0.0598111793 | 0.0061068872 |
| 校准到峰值 | 0.2405143240 | 0.0061068872 |

全体 RSA 增加 0.1807031446，而 clean-clean 相似度完全不变。

**该反例不是精确最大值、实际偏差估计、训练机制模拟或发生概率。**它只证明：聚合 RSA 和重叠比例不足以推出“未见文本上至少有多少 RSA 增益”。不能据此断言原实验的增益是由重叠造成的。

要计算固定检查点的真实影响，必须在旧验证集内剔除旧训练文本重叠项，保留相同检查点、层和原有中心化参数，重算 clean-clean RSA。若同时换 EMA 均值，测量口径也随之变化，需要单独报告。新 action_grouped 的验证集不能直接充当旧检查点的未见验证集，因为旧模型可能已训练过其中的文本。

## 外部 benchmark 与最终结论

这次发现的是内部 Social-Chemistry 划分的文本重叠，并未审计训练数据与外部 benchmark 的内容交叉。它不是“多少百分比的 benchmark 题目已见过”的计数。

仅凭上述比例，既不能给外部 ASR 扣除一个固定数值，也不能保证改划分重训后 ASR 不变。RSA 用于选模，重训还会改变模型参数；其对 benchmark 及 RSA-ASR 关联的影响需要检查点级别的稳健性核验。

## 复查

从仓库根目录运行：

```bash
python analysis/overlap_audit/audit_overlap.py
```

脚本只读取现有训练代码中的指定数据／指标函数，不加载 PyTorch、模型或网络资源。结果写入 `results.json`，其中保存全部输入文件的 SHA-256、原始计数、公式示例和合成矩阵的正定性下界。
